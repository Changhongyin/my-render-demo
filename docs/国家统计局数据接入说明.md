> 配套脚本：`fetch_nbs_prices.py`（根目录）｜自测：`tests/nbs_prices_test.py`（60 项，离线）
> 分工：`local_spider_v2.py` 写 `crops`（行情台账）｜`fetch_weather_alerts.py` 写 `weather`（气象预警）｜
> **本脚本只写 `nbs`**，三者互不覆盖。

## 一、数据发布里哪些数据对页面有用（已实测，2026-09-19 核对）

| # | 数据集 | 栏目与频率 | 农业相关字段（实测：2026年9月上旬 / 2026年8月） | 页面用途 |
|---|---|---|---|---|
| **A** | **《流通领域重要生产资料市场价格变动情况》** | `/sj/zxfb/`，**旬报（每月上/中/下旬，9:30 发布）** | 农产品：稻米（粳稻米）3981.0、小麦 2395.8、玉米（黄玉米二等）2236.8、大豆 4706.9、豆粕 3305.8、生猪（外三元）11.0 元/千克、棉花、花生、白糖；农业生产资料：尿素 1771.9、磷肥 4252.5、钾肥 3074.1、复合肥 3619.4、农药（草甘膦）25475.0 元/吨；另有柴油 8711.3 元/吨。**每行都带「本期价格 / 比上期涨跌（元）/ 涨跌幅（%）」，共 50 种产品** | ★★★ 卡片①「农资与饲料成本」 |
| **B** | **《居民消费价格》（CPI）** | `/sj/zxfb/`，**月度（每月 9–10 日 9:30）** | 2026年8月：CPI 同比 +0.8%、环比 +0.4%；**其中食品 同比 −1.4%、环比 +0.4%**；文中细项：鲜菜 −2.8%、蛋类 +15.0%、猪肉 −11.8%、水产品 −0.6%、鲜果 −2.5% | ★★ 卡片②「CPI 食品口径」/ analysis 官方口径 |
| C | 稻谷/早稻产量公告、年度统计公报 | `/sj/zxfb/`（如"关于2026年早稻产量数据的公告"）、`/sj/tjgb/` | 全国及分省产量 | ★ 供给面背景（写 notes，不做卡片） |
| D | 国家数据（data.stats.gov.cn） | 分省月度/年度数据库 | 分省 CPI、粮食产量、农业生产资料价格指数 | ❌ **接口实测 403（WAF UrlACL）**，见第二节 |

**单位天然对齐**：旬报是「元/吨」，÷1000 就是**元/公斤**，与页面 `crops[].unit = 元/公斤` 完全统一。
**最有价值的用法**：把统计局原粮价与页面成品粮价放一起看价差（例：小麦 2.3958 元/公斤 vs 富强粉 2.80 元/公斤 → 加工差价 ≈ 0.40 元/公斤）。

> 边界：统计局数据只到**全国 / 分省**，没有寿光/三元朱村级数据，也没有蔬菜批发价（那是农业农村部/寿光蔬菜集团的）。
> 所以 NBS 数据的定位是**宏观参照 + 投入端成本**，不替代现有的本地行情源。

## 二、取数方式：为什么选"列表页定位 + 正文表解析"

| 路线 | 实测结果 | 结论 |
|---|---|---|
| ✅ **公开页面表格解析**（本脚本采用） | `https://www.stats.gov.cn/sj/zxfb/`（列表）和文章页均 **HTTP 200**，UTF-8，**服务端直出 HTML**，数据在 `<table>` 里 | 稳定、无需 token、无 JS、无风控 |
| ❌ 国家数据 JSON 接口 | `data.stats.gov.cn/easyquery.htm?m=QueryData…` → **403 Forbidden**，响应体带 `eventID: … reason:UrlACL`；新前端 `/dg/website/page.html` 外壳 200 但 API 路径 403/404 | 本机 IP 被 WAF 规则拦，**不做主方案、不绕过** |
| ❌ 站内搜索 | `/search/s?qt=…` 结果由 JS 渲染（HTML 里没有结果）；其 XHR `/web/api/searchbox` → **404**；`so.stats.gov.cn` 不可达 | 不可用 |
| ⚠️ 山东地方补充（可选，第二阶段） | `http://tjj.shandong.gov.cn/` → 200（**仅 http，无 https**） | 需要时再评估 |

**页面解析的 4 个关键点（都已在代码里处理，并有自测覆盖）**

1. **定位最新一期**：列表页标题匹配「流通领域重要生产资料市场价格变动情况」；
   链接是相对路径 `./YYYYMM/tYYYYMMDD_数字.html`，用 `urljoin` 还原；
   翻页 `index_1.html / index_2.html …` 实测可回溯到 2024 年（`--lookback` 控制往前翻几页）。
2. **别写死 `tables[0]`**：文章页有 **4 张表**（正文数据表 + 附录说明表，各出现两次），
   必须按表头关键词（`产品名称 / 单位 / 本期价格`）认表；附录表表头是 `序号 / 监测产品 / 规格型号 / 说明`，要跳过。
3. **类目行**：`七、农产品（主要用于加工）` 这种行是「只有第一格有字、其余 4 格为空」，用它做分组。
4. **脏空格**：统计局页面把文字拆在多个标签里（`柴油（<span>0#</span>国<span>VI</span>）`），
   表格单元格必须**去标签时不加空格**，否则会得到 `柴油（ 0# 国 VI ）`。

## 三、数据结构：`data.json` 里的 `nbs` 块

```jsonc
"nbs": {
  "generator": "fetch_nbs_prices.py",
  "data_kind": "live",                      // live=真实抓取（本脚本没有 mock 模式）
  "fetched_at": "2026-09-19 16:23:25",
  "source": "国家统计局",
  "source_note": "数据来源：国家统计局；引用时请注明来源与期次，数值与口径不得篡改",

  "junbao": {                               // ① 旬报：农资与饲料成本
    "dataset": "流通领域重要生产资料市场价格变动情况",
    "title": "2026年9月上旬流通领域重要生产资料市场价格变动情况",
    "period": "2026年9月上旬",               // 幂等键：同期重跑不累积
    "published_at": "2026-09-14 09:30",
    "source": "国家统计局",
    "url": "https://www.stats.gov.cn/sj/zxfb/202609/t20260914_1965293.html",
    "total_products": 50,                   // 该期共监测 50 种产品（如实）
    "kept_products": 15,                    // 本页面保留的农业相关条目数
    "inputs": [
      { "group": "四、石油天然气",              // 统计局原文类目（原样保留）
        "group_key": "运输能源",                // 归一化类目：农产品 / 农业生产资料 / 运输能源
        "name": "柴油（0#国VI）",               // 原文产品名（未改写）
        "unit": "吨",                          // 原单位
        "price": 8711.3,                       // ★原值（元），未加工
        "price_per_kg": 8.7113,                // 换算值（元/公斤）= 原值 ÷ 1000
        "price_unit": "元/公斤",
        "change": 382.8,                       // 比上期涨跌（元）
        "change_pct": 4.6 }                    // 比上期涨跌幅（%）
    ]
  },

  "cpi": {                                  // ② CPI（月度）
    "dataset": "居民消费价格（CPI）",
    "month": "2026年8月",
    "published_at": "2026-09-09 09:30",
    "source": "国家统计局",
    "url": "https://www.stats.gov.cn/sj/zxfb/202609/t20260909_1965263.html",
    "value_kind": "指数（涨跌幅%）",
    "mom_pct": 0.4, "yoy_pct": 0.8, "ytd_yoy_pct": 0.9,
    "food_mom_pct": 0.4, "food_yoy_pct": -1.4, "food_ytd_yoy_pct": -0.8,
    "highlights": { "鲜菜": -2.8, "蛋类": 15.0, "猪肉": -11.8, "水产品": -0.6 }
  },
  "cpi_error": null                         // CPI 抓取失败时写原因，不影响旬报落盘
}
```

字段语义：`mom` = 环比（与上月比）、`yoy` = 同比（与上年同月比）、`ytd` = 年初至今累计同比。

**写入安全**：`merge_into_data()` 只做 `out["nbs"] = block`，随后逐个比较 `meta / crops / weather` 的
`json.dumps(..., sort_keys=True)`，任一不同就抛错中止——从机制上保证"不碰别人的数据"。

## 四、怎么跑（推荐顺序）

```bash
cd /Users/user/Documents/my-render-demo

# 1) 干跑：只打印，不写文件、不备份
python3 fetch_nbs_prices.py --dry-run

# 2) 只写临时文件，肉眼核对 JSON 结构
python3 fetch_nbs_prices.py --out /tmp/nbs.json

# 3) 确认没问题再写线上（自动备份 backups/data_nbs_YYYY_MM_DD.json，只留最近 7 份）
python3 fetch_nbs_prices.py

# 4) 只要农资数据、跳过 CPI
python3 fetch_nbs_prices.py --no-cpi --dry-run

# 5) 离线自测（60 项，不联网）
python3 tests/nbs_prices_test.py
```

## 五、前端接入（已实施）

`public/farm.html` 里新增了一张**蓝色系**卡片，位置在行情卡片（绿）和气象预警卡片（橙）**之后**，顺序固定为：
`行情 → 气象预警 → 官方参考`。实现要点：

| 项 | 实现 |
|---|---|
| 标题 / 副标题 | `📊 官方参考 · 农资与饲料成本` ＋ 副标题 `国家统计局 2026年9月上旬`（取 `junbao.source + ' ' + junbao.period`） |
| 数据来源 | 只读 `payload.nbs.junbao.inputs[]`，**不碰** `meta` / `crops` / `weather` |
| 分组 | 按 `group_key` 渲染，顺序 `农产品 → 农业生产资料 → 运输能源`，认不出的类目归到「其他」并排最后 |
| 每行 | 名称 ｜ `price_per_kg`（保留 2 位小数，单位写「元/公斤」）｜ `change_pct` |
| 涨跌配色 | 红涨（`.nbs-pct.up` `#e53935`）／绿跌（`.nbs-pct.down` `#2e7d52`）；**0 或缺失显示 `—`** 并用中性灰 `.flat` |
| 底部标注 | `数据来源：国家统计局 ｜ 发布日期：2026-09-14 ｜ 查看原文`（日期取 `published_at` 前 10 位；缺哪个就少写哪个，不编造） |
| 静默隐藏 | `nbs` 缺失 / 类型不对 / `junbao.inputs` 为空 → 整张卡片不渲染，不报错、不留空白 |
| 容错 | 脏行（`null`、非对象、缺字段、脏价格）被跳过，正常行照常渲染；缺失值显示 `—` |
| 安全 | 所有文本走 `escapeHtml()`；链接经 `safeUrl()` 只放行 `http/https`（挡掉 `javascript:` 等伪协议） |

样式：`.nbs-card`（浅蓝底 `#eaf4fe` + 左侧 8px 蓝色条 `#1e90ff`），与绿色行情卡、橙色预警卡一眼区分。
自测：`tests/frontend_test_gen.py` 里新增 9 项 CSS + 30 项渲染断言（含 XSS、伪协议、脏数据、三卡顺序）。

可选增强（未做）：把 `nbs.cpi.food_yoy_pct` 与 `highlights` 接进 `analysis.forecast` 的官方口径文案。

## 六、频率与合规

- **频率**：旬报 3 期/月、CPI 1 期/月 → 每天跑 1 次足够；脚本自带 1–3 秒随机延迟 + 重试，不要提高频率。
- **署名**：页面必须显示「数据来源：国家统计局」+ 期次/发布时间；不得修改数值与口径。
- **不绕过风控**：`data.stats.gov.cn` 被 WAF 拦就不碰它；不做代理、不做高频轮询。
- **备份**：写入前自动备份，独立前缀 `data_nbs_*`，不影响行情/预警脚本各自的备份。

## 七、排错表

| 终端提示 | 原因 | 怎么办 |
|---|---|---|
| 在列表页里没找到「流通领域重要生产资料市场价格变动情况」 | 栏目改版 / 页面暂时不可达 | 用 `--list-url` 指到新栏目，或 `--lookback 5` 多翻几页 |
| 页面里没找到正文数据表（表头应含「产品名称/单位/本期价格」） | 页面结构变了 | 先 `--out /tmp/nbs.json` 抓下来人工核对，再调整 `TABLE_HEAD_KEYS` |
| 旬报里没解析到农业相关条目 | 类目名变了（如「农产品」改名） | 检查 `FOCUS_GROUP_KEYS` |
| CPI 页面里没解析到「居民消费价格」这一行 | CPI 文章结构变了 | 旬报仍会正常写入；修 `parse_cpi_table` 即可 |
| HTTP 403 / 请求失败（已重试 N 次） | 被风控或网络问题 | 别提高频率，隔一会儿再试；不要用代理硬闯 |
| 写入失败 / 合并失败 | 目标文件权限或结构问题 | 检查 `data.json` 是否可写、是否含 `crops`（应为完整台账） |
