## 六、环境上的两个坑（下次别再踩）

1. **Windows 打的 zip 用反斜杠**，macOS `unzip` 会平铺成带 `\` 的垃圾文件 → 用 `/tmp/unzip_fix.py` 正确解压。
2. **`npm install` 会卡在 `@prisma/engines` postinstall**（去 AWS 下引擎，国内 ECONNRESET）→
   用 `--ignore-scripts` 或 `PRISMA_ENGINES_MIRROR` 指向 npmmirror；本项目根本没用到 Prisma。

## 六·补、交接包验尸发现的一个真问题

把交接包解到 **干净目录** 用 `npm ci --ignore-scripts && npm run build` 验证时，构建失败：

```
src/lib/db.ts(1,10): error TS2305: Module '"@prisma/client"' has no exported member 'PrismaClient'.
Failed to type check.
```

我本机之所以一直能过，是因为第一次 `npm install` 残留了 `node_modules/.prisma/client`（`prisma generate` 的产物）。
也就是说：**原项目在任何"没生成过 Prisma Client"的环境里都构建不过**（CI、换机器、`--ignore-scripts` 安装都会踩）。
处理：把死代码 `src/lib/db.ts` 改名 `src/lib/db.ts.bak`（全项目无人引用它），类型检查不再碰 `@prisma/client`。
要用 Prisma 时 `npx prisma generate` + 改回名字即可。改完干净目录里 `npm ci --ignore-scripts && npm run build` 通过。
